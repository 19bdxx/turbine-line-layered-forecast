**关键发现**：Ridge 在所有 12 个预测步长下，分层净功率 RMSE 均高于全局直接预测，且短步长惩罚最重（N=15 时 +13%），长步长惩罚逐渐减小（N=180 时仅 +3%）。

**建议**：对于 Ridge，**无论步长多长，均应使用全局直接预测，不建议使用分层净功率方案**。

## 八、综合结论与建议

### 8.1 最佳方案选择矩阵

| 场景 | 推荐方案 | 关键指标 |
|---|---|---|
| **超短期（N=15）线路层直接预测** | Ridge 全局预测 | RMSE = 12.30 MW，R² = 0.9799 |
| **短期（N=15）分层策略** | MLP 净功率 | RMSE = 13.64 MW，R² = 0.975，比 MLP 全局改善 14% |
| **中期（N=30–90）最优单一结果** | Ridge 全局预测 | RMSE 18.6～33.5 MW，全覆盖 |
| **中期（N=45–90）分层策略** | MLP 净功率 | RMSE 24.2～34.9 MW，优于所有树模型全局预测 |
| **长期（N≥105）最优** | Ridge 全局预测（RMSE 36～49 MW）或 MLP 净功率（RMSE 37～50 MW） | 二者非常接近 |
| **分层改善最大** | LightGBM / XGBoost 净功率，N=150–180 | 改善约 15% |
| **绝对禁止使用** | LSTM 分层净功率 | R² < 0，完全失效 |

### 8.2 关键数字摘要

- **最佳单次预测精度**：Ridge N=15，RMSE = **12.30 MW**，R² = **0.9799**  
- **MLP 净功率最大改善**：N=120，全局 60.93 → 净功率 39.67 MW，改善 **34.9%**  
- **树模型净功率最大改善**：XGBoost N=150，改善 **15.9%**  
- **Ridge 净功率最大退化**：N=15，退化 **12.9%**（因此 Ridge 应始终使用全局方案）  
- **LSTM 失效严重性**：净功率 RMSE 约为全局的 1.6～2.4 倍，R² 全部为负

### 8.3 后续优化建议

1. **补全 LightGBM 和 Random Forest 的全局指标**（N=45–120 区段），以便与 Ridge 进行完整对比，当前这些区间只有对比数据没有全局指标。

2. **MLP 超参数调优**：当前 MLP 全局预测在 N ≥ 120 时 R² < 0.5，但净功率 R² 仍有 0.66–0.79。建议对 MLP 架构（层数、神经元数、正则化）做系统搜索，有潜力将净功率 RMSE 进一步降低。

3. **LSTM 单机调试**：在重新使用前，需验证每台风机 LSTM 的输出量纲是否正确（单机功率单位 kW，汇总到线路时需 /1000 → MW）；建议打印单机预测 vs 真值时序图，确认无系统偏差。

4. **混合预测策略**：  
   - N ≤ 30 min：使用 **Ridge 全局预测**（精度最高，速度最快）  
   - 30 < N ≤ 90 min：使用 **MLP 净功率** 或 **Ridge 全局**（MLP 净功率此时 RMSE 更低）  
   - N > 90 min：使用 **MLP 净功率** 或 **XGBoost/LightGBM 净功率**（三者接近，可集成）
