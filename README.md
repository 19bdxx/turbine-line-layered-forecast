# 输电线分层预测系统 (Turbine Line Layered Forecast)

## 项目简介

本项目是一个**风电输电线功率分层预测系统**，针对某风电场的输电线（丙线）进行短期功率预测。系统采用**分层预测**策略：先对线路上的每台风机分别建立预测模型，再将各风机预测功率求和，并扣除输电线损耗，最终得到线路净输出功率预测值。同时与**全局预测**（直接对线路总功率建模）进行对比，评估两种策略的精度差异。

---

## 功能特性

- **数据预处理**：去除重复时间戳、过滤停机数据、对齐时间序列
- **数据质量检查**：检测各风机多字段的重复数据段异常
- **单机预测**：对每台风机（编号 153–158）分别训练 LightGBM 回归模型
- **全局预测**：对输电线聚合功率直接建模，作为对比基准
- **分层预测后处理**：汇总单机预测结果，查表计算线损，得到线路净功率预测
- **结果可视化**：生成 Plotly 交互式 HTML 图表及 Matplotlib 静态图，对比预测值与真实值
- **指标汇总**：输出 RMSE、MAE、R² 等评估指标的汇总 CSV

## 数据说明

### 输入数据字段

| 字段 | 说明 |
|------|------|
| `timestamp` | 时间戳（采样间隔 60 秒）|
| `LIMIT_POWER` | 线路限制功率（kW）|
| `ACTIVE_POWER_BING_PROCESS` | 丙线聚合有功功率（kW）|
| `ACTIVE_POWER_#153` ~ `ACTIVE_POWER_#158` | 各风机有功功率（kW）|
| `WINDSPEED_#153` ~ `WINDSPEED_#158` | 各风机风速（m/s）|
| `REACTIVE_POWER_#153` ~ `REACTIVE_POWER_#158` | 各风机无功功率（kvar）|
| `STATUS_#153` ~ `STATUS_#158` | 各风机运行状态 |

### 数据过滤规则

- 剔除 `LIMIT_POWER` 在 0–900 之间的数据（对应停机或限功率状态）
- 将负值功率截断为 0
- 剔除时间间隔不连续（> 60 秒）的数据段

## 模型说明

### 特征构造

采用**滑动窗口**方式构建时序特征：

- **回溯步长 M = 60**（即过去 60 个时间步，约 60 分钟）
- 每步特征：当前时刻的平均风速 + 有功功率
- 共 2 × M 个输入特征

### 预测步长

| 预测步长 N | 对应预测时长 |
|-----------|-------------|
| 60 步 | 约 1 小时 |
| 120 步 | 约 2 小时 |
| 180 步 | 约 3 小时 |

### LightGBM 超参数

```python
params = {
    "learning_rate": 0.02,
    "num_leaves": 127,
    "max_depth": 12,
    "early_stopping_rounds": 30
}
```

数据集按 **80/20** 划分训练集与测试集。

## 运行流程

按以下顺序依次执行各脚本：

```
1. #0构建数据集.py        # 清洗原始数据，输出干净的 CSV
2. #1检查重复时间.py       # 检查数据质量（可选）
3. 全局预测.py             # 训练全局模型（基准对比）
4. demo2.py                # 训练 6 台风机的单机模型
5. 预测结果汇总.py          # 汇总各风机预测结果与评估指标
6. 预测结果分析.py          # 计算线损、获得分层预测净功率
7. 输电线_风机集合功率对比.py # 可视化与误差分析
```

> **注意**：脚本中的数据路径目前为 Windows 本地路径（如 `G:\...`），移植到新环境时建议将各脚本中的路径提取为顶部变量或通过环境变量（如 `os.environ`）统一配置，避免分散修改。
